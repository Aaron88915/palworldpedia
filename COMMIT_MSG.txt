fix(data): fill real movement speed + base price, drop fake ranged ATK

pals.json carried three fabricated fields that were rendered on all 288 pal
pages. All three are now backed by paldb.cc (Palworld 1.0 data).

stats.speed - was 0 for 271/288 pals, so every page showed a "移动速度 0 / C"
card. The 15 non-zero values were paldb's RunSpeed (200-3000), which confirms
the field's real meaning. Now filled for 287/288 pals from the Movement block
of each paldb pal page. Measured distribution: min 200 / median 550 / max 3000,
so the S/A/B/C thresholds were rebuilt on that scale (>=800 / >=650 / >=500).
Result: S 45 / A 55 / B 80 / C 107.

stats.price - was 0 for 271/288 pals (showing "售价 0 金币"). The value lives in
the paldb stat row labelled with the Gold Coin item link; its tooltip reads
"313 - 19900", the game's cheapest and priciest Pal base value. Extracted for
286/288 pals. Every one of the 16 values we already had agrees with paldb, and
independent sources confirm the parse: Cattiva 436 (capture.price), Lamball
421, Chikipi 313, Fuack 376, Jetragon 4452, Frostallion 4695, Dumud Gild
19900, Turtacle Terra 14950, Mau Cryst 385 (58% of Mau's 665), Kingpaca Cryst
1624, Gloopie Primo 1612, Croajiro Noct 1254.

stats.attack.ranged - removed. Palworld Pals have a single attack property;
there is no ranged attack stat. The field was 0 for every pal and rendered a
meaningless "远程攻击 0" card on all 288 pages. Also dropped from the Pal type
and the i18n string table.

The stat cards for movement speed and price are now only rendered when the
value exists, so a pal with no source data shows nothing instead of a zero.

Verified: 1790 pages built, 0 errors; 0 pages still showing 远程攻击 /
Ranged ATK; 0 broken internal links.
